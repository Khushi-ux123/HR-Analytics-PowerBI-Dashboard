# HR Analytics Dashboard – Power BI

## 📊 Project Overview

An interactive HR Analytics Dashboard developed using Microsoft Power BI
to analyze employee attrition, workforce demographics, salary distribution,
job roles, and years of service.

## 🎯 Objectives

- Analyze employee attrition
- Identify attrition patterns across age groups
- Analyze attrition by salary slab
- Understand education demographics across departments
- Analyze attrition by job role
- Study attrition trends across years of service
- Provide interactive filtering for HR analysis

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Employee Count | 1,480 |
| Attrition Count | 238 |
| Attrition Rate | 16.1% |
| Average Age | 36.9 |
| Average Salary | 6,505 |
| Average Tenure | 7.0 years |

## 📈 Dashboard Visuals

- Attrition Trends Across Education Fields
- Attrition Analysis by Age Group
- Education Demographics Across Department
- Attrition Analysis by Salary Slab
- Employee Attrition Trends Over Years of Service
- Attrition by Job Role
